# Performance Review

Use this when the user provides screenshots or metrics after publishing.

## Extract

Capture what is visible:

- platform;
- views;
- average watch time;
- completion rate;
- 2-second skip rate;
- 5-second completion rate;
- likes/comments/shares/saves;
- follows/profile visits/leads if visible;
- publish time and title/hook if known.

## Diagnose

Prioritize in this order:

1. First 2 seconds.
2. First 5 seconds.
3. Average watch time.
4. Completion rate.
5. Engagement and follows.
6. Conversion signals.

## Write Memory

Append an actual record to `performance-ledger.jsonl`, then update:

- `winning-patterns.md` if something worked.
- `forbidden-patterns.md` if something clearly failed.
- `content-memory.md` for next experiment.

## Forecast

Predictions should include:

- p50 views;
- likely range;
- high case;
- confidence;
- drivers;
- risks.
