# Script System

Use the creator profile, not a fixed niche.

## Default Structure

For 35-60 second videos:

```text
0-2s: visual hook + concrete problem/result
2-8s: why this matters
8-35s: example, proof, or steps
35-50s: key takeaway or limitation
50-60s: follow/lead action
```

For 90-120 second videos:

```text
0-4s: trend, conflict, result, or pain
4-10s: what the viewer will get
10-90s: 1-3 dense sections
90-120s: summary and follow/lead action
```

## Hook Patterns

- Contrarian: "Most people are doing X wrong."
- Result proof: "This saved me X hours / generated Y result."
- Risk: "This mistake makes your AI output useless."
- Scene: "Your boss asks for X before tomorrow."
- Comparison: "With plugin A vs without plugin A."

## Requirements

- Use concrete people, tasks, and outcomes.
- Prefer "scene -> action -> result" over feature lists.
- Do not reuse a niche-specific ending unless the creator profile says so.
- If the user provides a script, preserve its core meaning and only clean line breaks/punctuation.
