# Retention Rules

Short-video cold start depends heavily on the first 2 and 5 seconds.

## First 2 Seconds

Must show a visible subject, not only a title or background.

Good opening subjects:

- before/after comparison;
- wrong way vs right way;
- result proof;
- real interface or generated output;
- concrete example;
- data change;
- finished product preview.

## First 5 Seconds

The viewer should understand:

- what problem this video solves;
- why it matters;
- what concrete example/result they will see.

## Fix For Opinion/Course Videos

If the script starts with a lesson, opinion, or course takeaway, default to:

```text
wrong method vs correct method
```

Example:

```text
wrong: "Help me make a game"
right: "Unity3D, Steam, reference gameplay, save system, controller, docs"
```

## Fix For Tool Videos

If the script introduces a tool, default to:

```text
problem/result first -> tool name later
```
